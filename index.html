各授業回の学習事項

第1回 WWW と HTML

今回のwebコンテンツ作成では、プロトコル、サーバ、パスなどURLがそれぞれどのような意味を持つかなどの基本知識を身につけた。pはタグを表し文を入れることができる。 strongで強調やhの後につける数字によって見出しの大きさを変え、ul/ol/liで番号付きのリストなどを作成することができる。 dl/dtを使い段落分けをし、文章を読みやすくする。 imgを使い画像の埋め込み、a/hrefなどを使いハイパーリンクの埋め込みなどの様々なwebサイト作成に欠かせない基本知識を身につけることができたと思う。

演習の成果: 演習1-4:HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

今回のwebコンテンツ作成では、CSSによるwebページの装飾方法を身につけた。リンクでも、訪れたことのないサイトの表示方法、訪れたことのあるサイト、 触れたらどのように表示するかなど細かく決めることができる。bodyでページ全体を選択し、backgroundを使い背景色を設定する。 htmlでclass名を割り当てcssで編集する際に指定するなど関係性が高い。cssを使う際は忘れずに『link rel="stylesheet" href="style.css">』を 設定しなければ適応されない。

演習の成果: 演習2-3:medialabo/index.html を編集しよう

第3回 JavaScript の基本

今回のwebコンテンツ作成では、JavaScriptによるWebページへの機能追加方法を学んだ。 JavaScriptはWebページに動きを与えるプログラミング言語であり、ボタンを押した際の処理や表示内容の変更などを実現できる。 JavaScriptを利用する際は、HTMLファイル内でscriptタグを使用するか、外部のJavaScriptファイルを読み込む必要がある。 また、変数や関数、イベント処理などの基本的な文法を学び、ユーザーの操作に応じてページの内容を変更できることを理解した。 HTMLが構造、CSSが装飾を担当するのに対し、JavaScriptはWebページの動作や対話機能を担当していることが分かった。

演習の成果: 演習3-6: オブジェクトの参照
