「Webコンテンツ作成」の成果

本テーマについて

このテーマの学習目的は、HTMLやCSS、JavaScriptを用いて、 利用者が見やすく使いやすいWebページを作成する技術を身に付けることである。 目標は、検索機能や画面表示などを実装できるようになり、 Webページ制作を通して課題解決能力を養うことである。

プロジェクトの課題について

今回のWebページ作成では、利用者が検索しやすいように検索キー一覧を枠で表示し、 必要なジャンルコードをすぐ確認できるよう工夫した。 また、検索結果が見やすく表示されるようにレイアウトを意識した。 苦労した点は、JavaScriptとHTMLを連携させて検索機能を正しく動作させることや、 Ajax通信を用いて取得したデータを画面に表示することである。 エラーが発生した際には原因を一つずつ確認しながら修正し、 最終的に検索機能を完成させることができた。 今回の課題を通して、HTML・CSS・JavaScriptが連携して Webページが動作する仕組みを理解するとともに、 利用者の視点で見やすさや使いやすさを考えることの大切さを学んだ。

プロジェクト課題で作成したページ: project.html

数当てゲーム

「数当てゲーム」では、JavaScriptのイベント処理とDOM操作を用いて、ユーザーが入力した数値を判定するプログラムを作成した。 プログラムを作成する前に、Firefoxの開発者ツールのコンソール画面を利用し、document.querySelector()を使ってHTML要素を正しく取得できるか確認した。 また、textContentやvalueを参照して要素のテキストや入力値を取得できることを確かめ、DOMの基本的な操作方法を理解した。 その後、ボタンにクリックイベントを登録し、入力された数値と正解の数値を比較する処理を実装した。 判定結果に応じて「もっと大きい」「もっと小さい」「正解です」などのメッセージを画面上に表示し、さらに挑戦回数も更新されるようにした。 今回の演習を通して、DOMを利用した要素の取得や更新の方法だけでなく、イベント処理によってWebページに動的な機能を追加する仕組みについて理解を深めることができた。

数当てゲームのページ: kazuate.html

各授業回の学習事項

第1回 WWW と HTML

今回のwebコンテンツ作成では、プロトコル、サーバ、パスなどURLがそれぞれどのような意味を持つかなどの基本知識を身につけた。pはタグを表し文を入れることができる。 strongで強調やhの後につける数字によって見出しの大きさを変え、ul/ol/liで番号付きのリストなどを作成することができる。 dl/dtを使い段落分けをし、文章を読みやすくする。 imgを使い画像の埋め込み、a/hrefなどを使いハイパーリンクの埋め込みなどの様々なwebサイト作成に欠かせない基本知識を身につけることができたと思う。

演習の成果: 演習1-4:HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

今回のwebコンテンツ作成では、CSSによるwebページの装飾方法を身につけた。リンクでも、訪れたことのないサイトの表示方法、訪れたことのあるサイト、 触れたらどのように表示するかなど細かく決めることができる。bodyでページ全体を選択し、backgroundを使い背景色を設定する。 htmlでclass名を割り当てcssで編集する際に指定するなど関係性が高い。cssを使う際は忘れずに『link rel="stylesheet" href="style.css">』を 設定しなければ適応されない。

演習の成果: 演習2-3:medialabo/index.html を編集しよう

第3回 JavaScript の基本

今回のwebコンテンツ作成では、JavaScriptによるWebページへの機能追加方法を学んだ。 JavaScriptはWebページに動きを与えるプログラミング言語であり、ボタンを押した際の処理や表示内容の変更などを実現できる。 JavaScriptを利用する際は、HTMLファイル内でscriptタグを使用するか、外部のJavaScriptファイルを読み込む必要がある。 また、変数や関数、イベント処理などの基本的な文法を学び、ユーザーの操作に応じてページの内容を変更できることを理解した。 HTMLが構造、CSSが装飾を担当するのに対し、JavaScriptはWebページの動作や対話機能を担当していることが分かった。

演習の成果: 演習3-6: オブジェクトの参照

第4回 DOM と JavaScript

今回の授業では、JavaScriptを用いたイベント処理とDOMについて学んだ。 これまでHTMLやCSSではWebページの構造や見た目を作成してきたが、JavaScriptを利用することでユーザーの操作に応じてページの内容を動的に変更できることを理解した。 特に、querySelector()を使った要素の検索や、textContentを利用したテキストの取得・変更の仕組みが印象に残った。 また、ボタンのクリックイベントにイベントハンドラを登録することで、入力された氏名を取得し、 挨拶文を表示するプログラムを作成できたことから、Webページと利用者のやり取りの基本的な仕組みを学ぶことができた。 今後はより複雑なイベント処理やDOM操作についても理解を深め、実践的なWebコンテンツを作成できるようになりたい。

演習の成果: 演習4-10: 足し算ページ

第5回 イベント処理

今回の授業ではJavaScriptを用いたDOMの高度な操作について学んだ。 前回は、DOMの検索やテキストの参照・変更、そしてinput要素の値取得といった基本的な機能を扱ったが、 今回はさらに一歩進んで、要素の新規作成・属性の編集・要素の削除といった、Webページを動的に構築するための重要な機能を理解することができた。 特に、createElement()を使って新しい要素を作成し、insertAdjacentElement()を用いてページ上の任意の位置に配置する流れが印象に残った。 また、setAttribute()による属性の追加や変更、remove()による要素の削除など、 HTMLを直接書き換えることなくJavaScriptだけでページの構造を変えられることに驚いた。 演習では、リストに新しい項目を追加したり、画像の src 属性を設定したり、不要な要素を削除したりと、実際にDOMを操作することで理解が深まった。 これらの操作を組み合わせることで、ユーザーの操作に応じてページ内容を柔軟に変化させるWebコンテンツを作成できるようになると感じた。 今後は、今回学んだDOMの操作をさらに応用し、より複雑なページ構成や動的なUIを実現できるように理解を深めていきたい。

演習の成果: 演習5-7:DOMプログラミング(2)

Webページ作成実習における工夫点・苦心点・強調点・感想


webコンテンツ作成では、HTML、CSS、JavaScriptを用いてWebページを作成し、授業で学習した内容を実際のプログラムとして形にすることができた。 HTMLだけではなく、CSSやJavaScriptと組み合わせることで、見やすく操作しやすいWebページを作成できることを学んだ。

工夫した点は、CSSを利用してページ全体を見やすくしたことである。Gridレイアウトを利用して情報を整理し、見出しにはグラデーションや文字色を設定して内容が分かりやすくなるよう工夫した。 また、リンクの色やマウスを重ねたときの表示を変更し、利用者が操作しやすいデザインを意識した。

JavaScriptでは、DOM操作を利用してページの内容を動的に変更する処理を作成した。新しい要素の追加や画像の変更、不要な要素の削除などを行い、HTMLを書き換えなくても画面を変更できることを理解した。 また、イベントハンドラを登録し、ボタンや要素がクリックされたときだけ処理が実行される仕組みも学んだ。 イベント処理では、クリックした要素だけに枠線を付ける機能を実装し、CSSとJavaScriptを組み合わせることで画面表示を変更できることを確認した。

数当てゲームでは、乱数や条件分岐を利用して正解・不正解や残り回数を判定するプログラムを作成した。 条件分岐の順番によって結果が変わるため、正しく動作させるために何度も確認しながら修正したことが印象に残っている。

Ajax通信の実習では、Axiosを利用してサーバからデータを取得する方法を学んだ。 ボタンを押したタイミングで通信を行い、その結果を画面に表示する仕組みを実装することで、Webページが外部のデータを利用して動作する仕組みを理解することができた。

苦労した点は、エラーが発生したときの原因を特定することである。 HTMLのid名とJavaScriptの指定が一致していなかったり、変数名を間違えたりすると正しく動作しなかったため、コンソールに表示されるエラーメッセージを確認しながら一つずつ修正した。 この経験を通して、デバッグの重要性を学ぶことができた。

今回の実習を通して、HTMLはページの構造、CSSはデザイン、JavaScriptは動作を担当するという役割を実践的に理解することができた。 また、エラーを確認しながら少しずつ改善していくことの大切さも学んだ。今後は今回学んだ内容を基礎として、より見やすく使いやすいWebページを作成できるようになりたい。
